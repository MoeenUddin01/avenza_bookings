3. Slot Concurrency & Pricing Matrix Engine

Real-Time State Machine

🟢 AVAILABLE

Open for booking. Dynamic price calculated.

🟡 LOCKED (15m)

Held in checkout session. Timer running.

🔴 BOOKED

Confirmed payment. Unavailable to others.

          sequenceDiagram
              participant Guest as Customer Browser
              participant API as booking.lock_slot API
              participant DB as MariaDB (FOR UPDATE)
              participant Worker as Background Scheduler

              Guest->>API: Click Slot (08:00 - 09:00)
              API->>DB: SELECT * FROM VenueSlotLock WHERE slot OVERLAPS FOR UPDATE
              alt Slot Available
                  API->>DB: INSERT VenueSlotLock (expires_at = now() + 15m)
                  API-->>Guest: Lock Acquired (200 OK + lock_id)
                  Guest->>Guest: Start 15:00 Countdown Timer
              else Slot Locked by Other Session
                  API-->>Guest: Error 409: Slot locked by another user
              end

              opt Payment Success
                  Guest->>API: process_mock_payment(lock_id, payment_token)
                  API->>DB: INSERT VenueBooking (PAID) & UPDATE Lock status=CONVERTED
                  API-->>Guest: Redirect to /b/:invite_token
              end

              opt Abandoned Checkout
                  Worker->>DB: Every 5m: UPDATE VenueSlotLock SET status=EXPIRED WHERE expires_at < now()
              end
